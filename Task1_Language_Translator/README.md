Language Translation Tool



About



The Language Translation Tool is a Python-based web application that translates text from one language to another.



Features



\- Simple and user-friendly interface

\- Supports multiple languages

\- Text input and translation output

\- Built using Streamlit and Python



Technologies Used



\- Python

\- Streamlit

\- deep-translator



How to Run



1\. Install Python.

2\. Install the required libraries:

&#x20;  "pip install streamlit deep-translator"

3\. Run the application:

&#x20;  "streamlit run app.py"
